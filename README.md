# wiqon.github.io

Página principal de **WIQON — Market Flow Intelligence**: enlaces a todas las
redes, estado en vivo de la estrategia, experimentos y servicios.

- `index.html` — la página (HTML + CSS + JS, sin dependencias).
- `estado.json` — estado público del filtro de tendencia en BTC.
- `scripts/actualizar_estado.py` — lo recalcula con datos públicos de Binance (sin claves).
- `.github/workflows/estado.yml` — lo ejecuta cada día a las 00:15 UTC.

Contenido educativo. No es asesoría financiera.
