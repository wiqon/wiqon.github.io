# Código fuente de wiqonlab.com

> ⚠️ **Este repositorio no es el sitio.** El sitio oficial de WIQON es **[wiqonlab.com](https://wiqonlab.com)**
> (en portugués: [wiqonlab.com/br](https://wiqonlab.com/br/)). Acá solo está el código que lo publica.

## Estructura

| Ruta | Qué es |
|---|---|
| `scripts/construir_web.py` | Genera `index.html` (ES) y `br/index.html` (PT-BR) desde una sola plantilla |
| `assets/` | Estilos, scripts del navegador, logo e ilustraciones |
| `scripts/actualizar_*.py` | Datos públicos: estrategia, noticias (RSS), tipo de cambio oficial, videos e inflación del FMI |
| `.github/workflows/` | Publicación automática con GitHub Pages (cada 30 minutos) |

Solo usa fuentes públicas y no contiene claves privadas.
Contenido educativo y de investigación. No es asesoría financiera.
